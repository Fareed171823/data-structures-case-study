# Data Structures Case Studies in C++

## About This Project

This repository contains eight C++ programs based on
real-world applications of Data Structures and Algorithms.

## Case Studies

1. Shopping List
2. Train Coaches
3. Parking Garage
4. Browser History using Stack
5. Package Weights using Merge Sort
6. Bank Account Numbers using Hash Table and Linear Probing
7. Employee IDs using Binary Search Tree
8. Connecting Cities using Prim's Algorithm

## Technologies Used

- C++
- Data Structures
- Algorithms
- GitHub

## Learning Objectives

- Understand important data structures.
- Implement algorithms using C++.
- Practice problem-solving.
- Learn to manage projects using GitHub.
